# What does this implement/fix?

Updates Yandex Music Connect (Ynison) from v3.4.2 to v4.3.5. The provider follows
Music Assistant's player-owned AudioSource lifecycle, supports repeat/shuffle and
logical queue navigation, and improves heartbeat, token recovery and transport
handling. Dynamic PCM transitions now survive core teardown, and rapid queue
controls preserve each other's settings before the server echo arrives.

**Breaking configuration change:** existing standalone-credential or automatic-player
instances must be reconfigured to select a configured Yandex Music provider and a
concrete Music Assistant player. Ynison reads credentials from that linked account
and derives its device name from the selected player. Credentials are not migrated.

**Related issue (if applicable):** [provider #125](https://github.com/trudenboy/ma-provider-yandex-ynison/issues/125)
