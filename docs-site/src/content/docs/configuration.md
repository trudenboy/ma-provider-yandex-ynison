# Настройка Yandex Music Connect

## Предварительные условия

Сначала добавьте и авторизуйте обычный провайдер **Yandex Music**. Ynison не
поддерживает отдельный QR-вход, ручную вставку music token или собственное
хранение session token. Если Yandex Music ещё не настроен, мастер Ynison
завершится сообщением об отсутствующей зависимости.

## Добавление экземпляра

1. Откройте **Music Assistant → Настройки → Плагины**.
2. Нажмите **Добавить плагин** и выберите **Yandex Music Connect (Ynison)**.
3. В поле **Аккаунт Yandex Music** выберите связанный экземпляр.
4. Выберите **Плеер Music Assistant** или оставьте **Авто**.
5. Задайте **Имя устройства в Яндекс Музыке**.
6. Сохраните настройку.

Если настроен один Yandex Music, мастер выбирает его автоматически. При
нескольких аккаунтах выбор обязателен. Повторное прохождение настройки меняет
аккаунт, целевой плеер и публикуемое имя.

Старые конфигурации с режимом собственных credentials необходимо перенастроить:
выберите существующий Yandex Music. Токены автоматически не переносятся.

## Целевой плеер

Значение **Авто** сначала выбирает плеер, который уже воспроизводит музыку, а
при его отсутствии — первый доступный. Явно выбранный плеер используется до
следующей перенастройки.

Параметр **Разрешить ручное переключение плеера** управляет выбором источника в
интерфейсе Music Assistant:

- включён — источник Ynison можно выбрать на другом плеере;
- выключен — воспроизведение закреплено за настроенным плеером.

При переносе источника предыдущий плеер останавливается. Одновременно один
экземпляр обслуживает только одну AudioSource-сессию.

## Формат звука

Ynison декодирует каждый трек в PCM с постоянным форматом на протяжении одной
сессии.

| Параметр | Значения | Поведение «Авто» |
|:---------|:---------|:-----------------|
| **Частота дискретизации** | 44100, 48000, 96000 Гц | Базово 44,1 кГц; реальный формат трека может повысить частоту, после чего она ограничивается возможностями плеера |
| **Разрядность** | 16 или 24 бит | 16 бит для lossy, 24 бит для lossless; реальный формат трека может уточнить значение |

Lossless без доступной подсказки начинается с 24 бит / 44,1 кГц, а не с
48 кГц. Это позволяет не пересэмплировать большинство CD-quality треков.
Явно выбранная частота имеет приоритет и не ограничивается автоматически.

Новый формат применяется со следующей AudioSource-сессии. Изменение параметров
во время текущего потока не меняет уже зафиксированный формат.

## Несколько аккаунтов и устройств

Провайдер поддерживает несколько экземпляров. Для каждой связки создайте:

1. отдельный Yandex Music для нужного аккаунта;
2. отдельный Yandex Music Connect (Ynison);
3. собственное публикуемое имя и, при необходимости, целевой плеер.

Постоянными OAuth-данными владеет Yandex Music. Ynison только читает их и может
временно обновить music token в памяти при наличии x_token.

## Device ID

Скрытый device_id генерируется один раз для экземпляра и сохраняет его
идентичность в Ynison между перезагрузками. Менять его вручную не требуется.
